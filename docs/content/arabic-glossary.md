# Arabic copy glossary (growdigital.com)

Register: Modern Standard Arabic for Gulf enterprise readers (KSA, UAE). Confident, plain and short. No literal
word-for-word translation: rewrite each sentence the way a native Saudi/Emirati marketing writer would.

## Rules
- Keep in Latin script: brand, product, partner and client names (Grow Digital, GrowShield™, Grow Bot, Athar, InCommerce,
  OneStore, Inveon, Mobilgi, Navinspire, GTech, SkySens, MaestroHub, Google Cloud, Microsoft Azure, Oracle, IBM, ERP, AI, IoT,
  PMO, SLA, KPI, UX/UI, API, L1–L3, etc. when they are acronyms).
- Western digits (0-9) and % as in the source: "71%", "24/7", "17 خدمة".
- Headline accent: the source marks one word with *asterisks* (e.g. "Growth you can *measure*."). Keep exactly ONE word
  (or short phrase) wrapped in *asterisks* in the Arabic headline, ideally the word carrying the same meaning.
- Never change ids, slugs, hrefs, anchors, image ids, numbers like num: "01", enum values (group: "cloud", kind: "own",
  category: "AI"), or object structure. Only translate human-readable strings.
- Punctuation: Arabic comma "،" and question mark "؟"; full stop "." stays. No exclamation marks.
- Use "المملكة العربية السعودية" / "السعودية" and "الإمارات العربية المتحدة" / "الإمارات"; "الخليج".
